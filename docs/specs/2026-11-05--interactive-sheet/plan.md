# Plan: Интерактивный Чарлист (Часть 1)

## 1. Backend (Laravel)

### 1.1 Конфигурация и Схема
*   **Конфиг:** Создать `config/sheet_schema.php`. 
    Структура: массив групп (например, `attributes`, `abilities`, `state`). В каждой группе — массив статов (ключ => название). 
    *Пример:* `['strength' => 'Сила', 'dexterity' => 'Ловкость']`.
*   **Миграция 1:** Добавить `stats` (jsonb, nullable) в таблицу `characters`.
*   **Миграция 2 (Data Migration):** Перенести данные из `character_states` (blood_pool, willpower_current, health_level) в JSON-поле `characters.stats`. После переноса таблицу `character_states` и связанные модели/контроллеры можно будет удалить/заморозить (в рамках этой задачи мы их отключаем).

### 1.2 Модели и API
*   **Модель:** В `Character` добавить cast `stats => array` (или `json`).
*   **API:** Обновить `CharacterSheetReader::aggregate()` — добавить возврат поля `stats`.
*   **API:** Создать эндпоинт `PATCH /api/characters/{character}/stats` (или использовать существующий `updateState`), который принимает массив `stats` и сохраняет его.
*   **Права:** `CharacterPolicy::update` (владелец PC или storyteller).

## 2. Frontend (Vue 3)

### 2.1 Логика и Компоненты
*   **Схема:** Создать composable `useSheetSchema.js`, который загружает структуру групп статов (можно захардкодить на фронте или отдавать через API из конфига, чтобы фронт и бэк были синхронизированы).
*   **Компонент `StatsGrid.vue`:**
    *   Принимает объект `stats`.
    *   Рендерит группы (Атрибуты, Способности, Состояние).
    *   Рендерит 5 точек (или 10 для крови/воли) для каждого стата.
*   **Логика клика (по ТЗ):**
    *   Если точка пустая (0): клик ставит значение `current + 1`, но помечает его как `is_temporary`.
    *   Если точка временная (красная): клик делает её постоянной (черной).
    *   Если точка постоянная (черная): клик удаляет её (значение `current - 1`).
*   **Режим редактирования:**
    *   Кнопка «Редактировать» / «Закончить редактирование».
    *   Если режим выключен, клики по точкам игнорируются (или скрыты).

### 2.2 Интеграция
*   В `CharacterSheetView.vue` заменить старый блок состояний (`SheetStateSection.vue`) и блок картинки на новый `StatsGrid.vue`.
*   В `ProfileView.vue` / `SheetViewer.vue` (если там отображается чарлист) также подключить `StatsGrid.vue`.

## 3. Тестирование
*   `CharacterStatsTest`: проверка API (сохранение/чтение JSON).
*   Ручная проверка UI (режим редактирования, логика кликов).

## 4. Риски
*   Перенос крови, Воли и здоровья из `character_states` в `characters.stats` может потерять значения.
*   Пока живы `CharacterState` и `PUT /state`, лист и старая форма могут разойтись.
*   **Вынесено из критериев приёмки:** `config/sheet_schema.php`; колонка `characters.stats` (`jsonb`, cast `array`); `PATCH /api/characters/{character}/stats`; право `CharacterPolicy::update`. Точки в реализации — массив `0/1/2` (пусто / постоянно / временно), не отдельный флаг. Кровь и Воля — до 10 точек, остальные статы — до 5. Удаление `CharacterState` в эту часть не входит.
