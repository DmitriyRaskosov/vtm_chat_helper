# Spec: Keyword-triggered RAG по лору (Чанки)

**Status:** Completed
**Date:** 2026-11-08

## 1. Контекст и Цель
Текущий `WorldLoreProvider` подает статьи лора целиком. Если статья большая (5-10 тысяч символов), она раздувает контекст нерелевантными деталями и может превысить лимит токенов. 
Цель — внедрить RAG по чанкам (кускам) статей. Система будет находить упоминания сущностей (например, «Катаяны») в промпте мастера и последних сообщениях, а затем подтягивать только самые релевантные куски этой статьи.

## 2. User Stories
*   **US-1:** Как система, я хочу разбивать большие статьи лора на куски, чтобы не превышать лимиты контекста.
*   **US-2:** Как рассказчик, я хочу, чтобы при упоминании «Катаянов» в чате, Copilot подтягивал только ту часть статьи, которая относится к текущей ситуации.

## 3. Acceptance Criteria (EARS)
*   **AC-1 (БД):** THE system SHALL создать таблицу `canon_lore_chunks` для хранения кусков статей с их векторными эмбеддингами.
*   **AC-2 (Нарезка):** THE system SHALL создать консольную команду для нарезки статей из `resources/canon/lore/`. Статья режется по заголовкам `##`, а если заголовок больше 340 токенов — по абзацам.
*   **AC-3 (Триггеры):** WHEN формируется контекст Copilot, THE system SHALL сканировать `storyteller_prompt` и `recent_messages` на наличие имен или алиасов сущностей мира (`world_entities`).
*   **AC-4 (Retrieval):** IF найдена сущность, связанная со статьей лора, THE system SHALL использовать pgvector для поиска и возврата ровно ДВУХ самых релевантных чанков из этой статьи (семантически близких к тексту промпта).
*   **AC-5 (Контекст):** Найденные чанки передаются в промпт через новый `LoreRagProvider`. Общий лимит секции — не более 700 токенов (2 чанка по 340 + запас).

## 4. Out of Scope
*   Изменение старого `WorldLoreProvider` (он продолжит работать для запросов по кланам/сектам).
*   Ручное редактирование чанков через UI.

## 5. Post-Implementation Notes
*   Создана таблица `canon_lore_chunks` (нарезка по 340 токенов).
*   Реализован `LoreRagProvider`, который сканирует промпт и последние сообщения на `canonical_name` сущностей (`world_entities`; алиасы сняты по ADR-002).
*   Найденные чанки подтягиваются через pgvector (лимит 2 штуки, общий бюджет 700 токенов).
*   Провайдер зарегистрирован в `ContextAssembler` (перед `world_lore`).
*   DoD: `php artisan test` (829 passed), Pint, PHPStan, `docker compose exec frontend npm run build` — пройдены.
