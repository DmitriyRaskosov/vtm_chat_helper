# Spec: UI для редактирования промптов

**Status:** Completed
**Date:** 2026-11-08

## 1. Контекст и Цель
Сейчас промпты хранятся в `.md` файлах. Чтобы изменить стиль NPC или правила дневника, нужно лезть в код. Рассказчику это недоступно.
Цель — дать рассказчику интерфейс в Мастерской для редактирования промптов. Изменения сохраняются в БД (переопределяя файлы), с возможностью сброса к заводским настройкам. Каждый промпт должен сопровождаться понятным описанием и списком переменных. Плюс необходимо показать карту контекста (какие данные попадают в модель).

## 2. User Stories
*   **US-1:** Как рассказчик, я хочу менять тексты системных и пользовательских промптов прямо в UI, чтобы настраивать поведение NPC без разработчика.
*   **US-2:** Как рассказчик, я хочу видеть описание каждого промпта и список переменных (например, `{{name}}`), чтобы понимать, как он работает.
*   **US-3:** Как рассказчик, я хочу иметь возможность сбросить неудачные изменения к исходному состоянию (заводским файлам).
*   **US-4:** Как рассказчик, я хочу видеть полную схему того, какие данные попадают в контекст (биография, сцена, лор), чтобы лучше понимать работу ИИ.

## 3. Acceptance Criteria (EARS)
*   **AC-1 (Хранение):** THE system SHALL хранить измененные промпты в БД. Если изменений нет, система читает заводской `.md` файл.
*   **AC-2 (UI - Список):** В Мастерской (вкладка «Промпты») THE system SHALL отображать список всех доступных промптов, сгруппированных по модулям (Copilot, Дневник).
*   **AC-3 (UI - Редактирование):** WHEN рассказчик выбирает промпт, THE system SHALL показывать textarea с текущим текстом, кнопки «Сохранить» и «Сбросить».
*   **AC-4 (Справка):** THE system SHALL отображать название, описание и список доступных переменных для выбранного промпта.
*   **AC-5 (Сброс):** WHEN рассказчик нажимает «Сбросить», THE system SHALL удалять кастомную запись из БД, и UI загружает заводской файл.
*   **AC-6 (Валидация):** THE system SHALL запрещать сохранение пустого текста промпта.
*   **AC-7 (Карта контекста):** THE system SHALL предоставлять UI-кнопку «Карта контекста», при клике на которую открывается модальное окно с пошаговым списком всех секций (system, scene, biography и т.д.), попадающих в промпт для каждого прохода (Topics, Reply, Diary Writer).

## 4. Out of Scope
*   Создание совершенно новых промптов с нуля.
*   История версий.

## 5. Post-Implementation Notes

- Создана таблица `prompt_overrides` (хранение кастомных промптов поверх файлов).
- `PromptRepository` проверяет БД, затем файл (fallback).
- API (GET/PUT/DELETE) защищён Policy (только storyteller) и whitelist ключей в `config/prompts_metadata.php`.
- UI в Мастерской: редактор промптов, подсказки с переменными, защита JSON-промптов (`is_json_required`).
- Добавлена «Карта контекста» со схемой всех 3 проходов (Topics, Reply, Diary Writer).
