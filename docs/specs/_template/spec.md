## 3. Acceptance Criteria

<!--
  Формат EARS:
    WHEN <триггер>, THE system SHALL <ответ>
    IF <условие>, THE system SHALL <ответ>
    WHILE <состояние>, THE system SHALL <свойство>
    THE system SHALL <свойство>

  Правила:
  - Каждый AC — проверяемое поведение, а не инфраструктурная задача.
  - Никаких имён событий, классов, технологий, контейнеров.
  - Избегай «мгновенно», «быстро», «удобно» — нужны измеримые формулировки
    или явная ссылка на критерий («в рамках одного WS-события»).
  - Если AC касается времени — указывай порог (например, «< 500 ms»).
-->

* **AC-1:** WHEN ... THE system SHALL ...
* **AC-2:** IF ... THE system SHALL ...
