# Plan: Исправление UI-багов Мультиперсонажей

## 1. Backend (Laravel)
### 1.1 Авторизация (Policies)
*   Проверить `SceneParticipantPolicy` (или аналогичную). 
*   Убедиться, что игрок может добавлять/убирать **своего** персонажа из текущей активной сцены (через `SceneParticipantController`).
*   *Если игрок этого не может:* обновить Policy, чтобы разрешить действие, если `$user->id === $character->user_id`.

## 2. Frontend (Vue 3 - Багфиксы)

### 2.1 Кэширование и Реактивность
*   **Аватар:** В `useProfile.js` или `ProfileView.vue` при формировании URL аватара добавлять query-параметр `?v={timestamp}` после успешной загрузки, чтобы браузер сбрасывал кэш.
*   **Чарлист:** В `useCharacterSheetImage.js` и `SheetViewer.vue` убедиться, что после загрузки нового файла `URL.revokeObjectURL` вызывается для старого, и создается новый `URL.createObjectURL`, а состояние компонента обновляется.

### 2.2 Списки персонажей
*   **RightSidebar / Участники:** Убрать логику `.find(c => c.user_id === user.id)`, из-за которой отображается только первый персонаж игрока. Выводить всех персонажей, принадлежащих игроку.

## 3. Frontend (Vue 3 - Сцена и Чат)

### 3.1 Селектор в Чате (`ChatComposer.vue`)
*   Фильтровать выпадающий список «Писать от лица»: показывать только тех персонажей игрока, которые уже есть на сцене (`is_current === true`).
*   Если на сцене нет ни одного PC игрока — скрывать селектор и блокировать ввод (или показывать кнопку «Выйти на сцену»).

### 3.2 Личный Кабинет (`ProfileView.vue`)
*   Добавить кнопку «Выйти на сцену» (если PC нет на сцене) и «Покинуть сцену» (если PC на сцене). 
*   Кнопки вызывают `POST /api/scenes/{scene}/participants` и `PATCH /api/scenes/{scene}/participants/{character}`.

## 4. Риски
*   Список участников, собранный через `.find` по `user_id`, снова скроет второго персонажа.
*   Аватар по постоянному пути `avatars/{id}.jpg` останется в кэше браузера без метки версии.
*   **Вынесено из критериев приёмки:** cache-bust аватара (`?v=` и `updated_at`), чарлист через новый blob-url. Селектор чата фильтрует `is_current`. Доработка списка: `CharacterSheetController::index` отдаёт всех PC игрока, видимость — `CharacterVisibility::visibleIdsForPlayerCharacters()`.
