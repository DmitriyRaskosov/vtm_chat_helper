# Spec: Вкладки черновиков Copilot

Status: Completed

## 1. Контекст и Цель
Рассказчик сравнивает три варианта реплики НПС в правой панели. Сейчас все черновики выводятся вертикальным списком (`v-for` по `.draft-list` в `StorytellerCopilotPanel.vue`). Длинный текст выбранной карточки растягивает панель, появляется вертикальный скролл всей панели, и кнопку отправки приходится искать.

Цель: на экране всегда один черновик. Переключение — горизонтальными вкладками. Редактирование — в textarea. Вкладки и кнопка отправки остаются на месте, длинный текст скроллится только внутри поля.

## 2. User Stories
*   **US-1:** Как рассказчик, я хочу переключать варианты реплики вкладками, чтобы сравнивать их, не прокручивая всю панель.
*   **US-2:** Как рассказчик, когда я переключаю варианты реплики вкладками, чтобы сравнивать их, содержимое варианта реплики автоматически попадает в панель редактирования и отправки в чат. (реализация уже есть, просто не забыть об этом)
*   **US-3:** Как рассказчик, я хочу править выбранный вариант в поле и сразу видеть кнопку отправки, чтобы отправить реплику в чат независимо от длины текста.
*   **US-4:** Как рассказчик, я хочу держать список «На сцене» свёрнутым и видеть кнопку «Управление сценой» текстом, чтобы панель Copilot была на виду без прокрутки.

## 3. Acceptance Criteria
*   **AC-1:** WHEN есть сгенерированные черновики, THE system SHALL показывать горизонтальный ряд вкладок «Вариант 1», «Вариант 2», «Вариант 3» (по числу черновиков) и текст только выбранного варианта.
*   **AC-2:** WHEN рассказчик нажимает вкладку, THE system SHALL обновлять `selectedDraftIndex` и подставлять текст этого черновика в textarea (`editedDraft` через уже существующий `selectDraft`).
*   **AC-3:** WHILE выбран черновик, THE system SHALL держать кнопку «Отправить в чат от НПС» сразу под textarea. Вкладки и кнопка не уезжают из видимой области панели из-за длины текста.
*   **AC-4:** WHEN текст выбранного черновика длиннее поля, THE system SHALL скроллить сам textarea (`max-height`, `overflow-y: auto`). Панель вкладок и кнопка отправки остаются на месте.
*   **AC-5:** WHEN рассказчик отправляет выбранный (в том числе отредактированный) черновик, THE system SHALL по-прежнему публиковать его в чат от выбранного НПС. Смена вкладки не отправляет сообщение сама.
*   **AC-6:** WHEN открыта правая панель, THE system SHALL показывать блок «На сцене» свёрнутым, пока пользователь его не развернёт. Клик по ▼/▲ рядом с заголовком показывает и скрывает список участников. Состояние хранится в `localStorage` (`chat-scene-cast-open`): без записи и при значении не `1` список свёрнут. Кнопка управления сценой — на всю ширину блока, с текстом «Управление сценой» и обводкой; она видна и при свёрнутом списке.

## 4. Out of Scope
*   Изменение числа черновиков, промпта генерации и API `copilot/drafts`.
*   Превью памяти НПС, выбор НПС и поле ситуации.
*   Переименование кнопки отправки и смена контракта composable `useCopilotPanel` (кроме того, что UI вызывает уже существующий `selectDraft`).

## 5. Technical Context
*   Компонент: `frontend/src/components/chat/StorytellerCopilotPanel.vue`. Список `.draft-list` / `.draft-card` убрать из разметки черновиков.
*   Состояние уже есть в `frontend/src/composables/useCopilotPanel.js`: `drafts`, `selectedDraftIndex`, `editedDraft`, `selectDraft`, `sendAsNpc`.
*   Стили списка: `.draft-list`, `.draft-card` в `frontend/src/styles.css` (в том числе блок «Storyteller Copilot panel», где выбранная карточка снимает `max-height`). Стили, которые больше нигде не используются, убрать. Глобальный `styles.css` не реорганизовывать.
*   Проверка: `docker compose exec frontend npm run build`. Ручной прогон: переключить вкладки, поправить текст, отправить в чат.
