# Spec: Интерактивный Чарлист (Часть 2: Полные данные и Сетка V20)

**Status:** Completed
**Date:** 2026-11-06

## 1. Контекст и Цель
Текущий чарлист — это вертикальный список без структуры. Для удобства игры и подготовки к красивому UI мы должны переделать его в классическую сетку V20 (5 вкладок). Также нужно добавить недостающие данные: Дисциплины (с привязкой к клану), Добродетели, Человечность/Путь, Временную Волю (уже есть, просто поместить в нужное место), а также текстовые Преимущества (Merits/Flaws) и Пороки.

## 2. Acceptance Criteria (EARS)
*   **AC-1 (Структура UI):** THE system SHALL переделать `StatsGrid.vue` (или создать новый `CharacterSheetGrid.vue`) в интерфейс из 5 вкладок:
    1. **Шапка** (Имя, Клан, Поколение, Натура, Маска).
    2. **Атрибуты** (3 подтаба: Физические, Социальные, Ментальные).
    3. **Способности** (3 подтаба: Таланты, Навыки, Познания).
    4. **Преимущества** (3 подтаба: Дополнения, Дисциплины, Добродетели).
    5. **Статус** (Пороки/Достоинства, Человечность/Путь, Сила Воли (пост/врем), Запас Крови, Здоровье, Слабость).
*   **AC-2 (Дисциплины):** THE system SHALL подтягивать список доступных клану дисциплин (из `canon_clan_disciplines`) и выделять их в селекторе. Игрок может добавить любую дисциплину из канона и убрать ее. Каждая добавленная дисциплина имеет 5 точек.
*   **AC-3 (Текстовые данные):** THE system SHALL создать колонку `sheet_data` (jsonb) в `characters`. Структура: `{ "backgrounds": [...], "merits_flaws": [...], "weakness": "string" }`.
*   **AC-4 (Данные точек):** THE system SHALL обновить JSON `stats` для хранения всех групп точек (Атрибуты, Способности, Добродетели, Дисциплины, Человечность, Воля, Кровь, Здоровье).

## 3. Out of Scope
*   Красивый редизайн (цвета, картинки). Сейчас делаем строгую функциональную сетку.
*   Автоматический расчет очков создания персонажа.
