# Plan: Интерактивный Чарлист (Часть 2)

## 1. Backend (Laravel)
### 1.1 База данных и API
*   **Миграция:** Добавить `sheet_data` (jsonb) в `characters`.
*   **Конфиг:** Обновить `config/sheet_schema.php`, разбив статы на точные группы (Physical, Social, Mental, Talents, Skills, Knowledges, Virtues, State).
*   **API:** Обновить `CharacterSheetReader::aggregate`. Добавить в ответ `sheet_data`, а также массив `available_disciplines` (все из канона) с флагом `is_clan_discipline`.
*   **Сохранение:** Обновить `CharacterStatsService` и `PATCH /api/characters/{character}/stats` для приема `sheet_data` (текстовые поля) и обновленных `stats`.

## 2. Frontend (Vue 3)
### 2.1 UI и Компоненты
*   **Главный компонент:** Создать `CharacterSheetGrid.vue` (заменит `StatsGrid.vue`).
*   **Навигация:** 5 главных табов.
*   **Таб 1 (Шапка):** Отображение (или редактирование) базовых данных: Имя, Клан, Поколение, Натура, Маска. Уже имеется логика, посмотри на неё, реши, как будет проще - написать заново или использовать существующие наработки.
*   **Таб 2 (Атрибуты) и Таб 3 (Способности):** 3 колонки с точками (использовать уже написанную логику точек).
*   **Таб 4 (Преимущества):**
    *   Дополнения (Backgrounds): текстовый список (Name, Value).
    *   Дисциплины: список добавленных дисциплин (по 5 точек) + селект для добавления новых (с выделением клановых).
    *   Добродетели: 3 стата по 5 точек.
*   **Таб 5 (Статус):**
    *   Пороки/Достоинства (Merits/Flaws): текстовый список (Name, Points, Type).
    *   Человечность (10 точек).
    *   Воля (10 точек постоянной + 10 точек временной).
    *   Кровь (10 точек).
    *   Здоровье (текущая логика с уровнями).
    *   Слабость (текстовое поле).

## 3. Риски
*   Перенос старых данных (кровь, здоровье) в новые табы.
*   **Вынесено из критериев приёмки:** колонка `characters.sheet_data` (`jsonb`): `backgrounds`, `merits_flaws`, `weakness`. Дисциплины канона с флагом клановой (`canon_clan_disciplines` / `is_clan_discipline`) через `CharacterSheetReader`. Группы точек живут в `characters.stats`. UI — `CharacterSheetGrid.vue`, пять вкладок. Сохранение текстовых полей вместе со статами в `PATCH /api/characters/{character}/stats`.
