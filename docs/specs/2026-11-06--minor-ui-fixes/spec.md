# Spec: Minor UI Fixes and Polishing

**Status:** Completed
**Date:** 2026-11-06

## 1. Контекст и Цель
Основной функционал VTT (Чарлист, Кубы, Локации) готов. Однако в интерфейсе остались мелкие раздражители, которые портят пользовательский опыт: отсутствие аватарок в чате, неудобный скролл, неочевидные кнопки и рудименты старых ограничений (например, запрет на ЛК для рассказчика). 
Цель — устранить эти шероховатости, чтобы интерфейс ощущался целостным и профессиональным.

## 2. Acceptance Criteria (EARS)
*   **AC-1 (Аватары в чате):** WHEN в чате отображается сообщение от персонажа (PC или NPC) с загруженным аватаром, THE system SHALL показывать этот аватар рядом с именем автора (в IC и OOC).
*   **AC-2 (Иконка):** THE system SHALL заменить иконку «Чат» в левом боковом меню на 💬 (облачко сообщения).
*   **AC-3 (ЛК):** THE system SHALL позволять рассказчику открывать Личный кабинет без блокирующих сообщений.
*   **AC-4 (Скролл в чате):** WHEN пользователь прокручивает лог чата вверх, THE system SHALL показывать плавающую кнопку «↓» для быстрого возврата к последним сообщениям.
*   **AC-5 (Форматирование):** THE system SHALL корректно отображать переносы строк (Shift+Enter) в сообщениях чата.
*   **AC-6 (Hover):** Кнопки действий с сообщением (Удалить, Редактировать, OOC) SHALL появляться только при наведении курсора на сообщение, не засоряя эфир.

## 3. Out of Scope
*   Визуальная переделка самого чарлиста и окна кубов (вынесено в SDD №2).
*   Удаление старых рудиментарных блоков (вынесено в SDD №3).

## Post-Implementation Notes
- ЛК объединяет PC игрока и NPC хроник рассказчика, персонажи сгруппированы по хроникам.
- Аватары в чате (32x32), кнопка «Вниз» в логах IC/OOC, переносы строк, hover-эффекты на кнопках сообщений.
- Иконка чата заменена на 💬, заглушка ЛК рассказчика убрана.
