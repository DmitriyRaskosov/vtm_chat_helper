# Spec: Создание персонажа игроком

**Status:** Completed
**Date:** 2026-11-02

## 1. Контекст и Цель
Сейчас персонажей (PC) может создавать только рассказчик через Мастерскую. Игрокам приходится ждать мастера, чтобы начать играть. 
Цель фичи — дать игрокам возможность самостоятельно создавать базовую «шапку» персонажа, чтобы снизить нагрузку на рассказчика.

## 2. User Stories
*   **US-1:** Как игрок, я хочу создать персонажа в текущей хронике из своего Личного кабинета, чтобы начать играть, не дожидаясь действий рассказчика.
*   **US-2:** Как игрок, я хочу заполнить базовые поля (Имя, Клан, Концепция), чтобы персонаж появился в моем списке.

## 3. Acceptance Criteria (EARS)
*   **AC-1 (UI):** WHEN игрок открывает Личный кабинет, THE system SHALL показывать кнопку «Создать персонажа» (только если у игрока еще нет активного PC в текущей хронике).
*   **AC-2 (Валидация):** WHEN игрок отправляет форму, THE system SHALL валидировать `canonical_name` (обязательно, уникально в хронике), `clan_id` (обязательно, из справочника) и `concept` (опционально).
*   **AC-3 (Бэкенд):** WHEN форма отправлена успешно, THE system SHALL создавать запись с `character_type = 'player'`, `user_id = Auth::id()`, `chronicle_id = текущая хроника`.
*   **AC-4 (Лимит):** IF у игрока уже есть активный PC в этой хронике, THE system SHALL блокировать создание (скрывать кнопку в UI и возвращать 422/409 на бэкенде).
*   **AC-5 (Редирект):** WHEN персонаж создан, THE system SHALL перенаправлять игрока на страницу листа нового персонажа (`/c/:chronicleId/characters/:id`).

## 4. Out of Scope (Чего НЕ делаем в этой фиче)
*   **Глобальная библиотека / Копирование:** Создание персонажей вне хроник и перенос между ними. (Вынесено в Roadmap).
*   **Снятие лимита 1 PC:** Оставляем ограничение «один активный PC на игрока в хронике».
*   **Заполнение листа:** Игрок не заполняет дисциплины, биографию, traits, инвентарь. Только базовая шапка.

## 5. Post-Implementation Notes
Игрок создаёт шапку персонажа из Личного кабинета: имя, клан из каталога, концепция. Запись получает `character_type = player`, `user_id` текущего игрока и `chronicle_id` выбранной хроники. Чужой `user_id` и `character_type` из тела запроса не сохраняются. Второй активный персонаж в той же хронике отвечает 422. После создания открывается лист `/c/{chronicleId}/characters/{id}`.

Отклонения: кнопка «Создать персонажа» скрыта, когда в кабинете уже есть любой персонаж игрока, а не только активный PC текущей хроники. `clan_id` обязателен для игрока; рассказчик в Мастерской по-прежнему создаёт NPC без клана. Лимит имени 100 символов действует и на рассказчика.

Бэклог: Снятие лимита 1 PC и добавление селектора персонажа в чат.
