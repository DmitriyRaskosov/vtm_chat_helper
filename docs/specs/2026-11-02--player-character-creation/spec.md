# Spec: Создание персонажа игроком

**Status:** Completed
**Date:** 2026-11-02

## 1. Контекст и Цель
Сейчас персонажа игрока может создать только рассказчик в Мастерской. Игроки ждут мастера, чтобы начать. Игрок должен сам завести базовую шапку персонажа в текущей хронике и тем самым разгрузить рассказчика.

## 2. User Stories
*   **US-1:** Как игрок, я хочу создать персонажа в текущей хронике из личного кабинета, чтобы начать играть, не дожидаясь рассказчика.
*   **US-2:** Как игрок, я хочу указать имя, клан и концепцию, чтобы персонаж появился в моём списке.

## 3. Acceptance Criteria (EARS)
*   **AC-1:** WHEN игрок открывает личный кабинет и у него ещё нет активного персонажа игрока в текущей хронике, THE system SHALL показать кнопку «Создать персонажа».
*   **AC-2:** WHEN игрок отправляет форму, THE system SHALL требовать имя, уникальное среди персонажей этой хроники, и клан из справочника. Концепция может быть пустой.
*   **AC-3:** WHEN форма принята, THE system SHALL создать персонажа игрока в текущей хронике и назначить его этому игроку.
*   **AC-4:** IF у игрока уже есть активный персонаж игрока в этой хронике, THE system SHALL скрыть кнопку и отклонить повторное создание.
*   **AC-5:** WHEN персонаж создан, THE system SHALL открыть лист нового персонажа.

## 4. Out of Scope
*   Библиотека персонажей вне хроник и копирование между хрониками.
*   Снятие лимита «один активный персонаж игрока на хронику».
*   Заполнение дисциплин, биографии, черт и инвентаря. Только базовая шапка.

## 5. Post-Implementation Notes
Игрок создаёт шапку персонажа из Личного кабинета: имя, клан из каталога, концепция. Запись получает `character_type = player`, `user_id` текущего игрока и `chronicle_id` выбранной хроники. Чужой `user_id` и `character_type` из тела запроса не сохраняются. Второй активный персонаж в той же хронике отвечает 422. После создания открывается лист `/c/{chronicleId}/characters/{id}`.

Отклонения: кнопка «Создать персонажа» скрыта, когда в кабинете уже есть любой персонаж игрока, а не только активный PC текущей хроники. `clan_id` обязателен для игрока; рассказчик в Мастерской по-прежнему создаёт NPC без клана. Лимит имени 100 символов действует и на рассказчика.

Бэклог: Снятие лимита 1 PC и добавление селектора персонажа в чат.
