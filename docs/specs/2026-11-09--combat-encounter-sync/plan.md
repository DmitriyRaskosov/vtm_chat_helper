# Plan: Боевая Секвенция Сцены (Этап 2: UI)

## 1. Frontend (Vue 3)
### 1.1 Компоненты
*   `CombatTracker.vue` (плавающее окно, можно свернуть).
    *   Горизонтальный список `div.tracker-item`.
    *   Внутри: `<img>` аватара, имя, бейдж инициативы.
    *   CSS: `border: 2px solid gold` для активного.
*   `CombatControls.vue` (панель управления для storyteller).
    *   Кнопка «Следующий ход».
    *   Кнопка «Собрать инициативу» (запускает `POST /roll-initiative`).
    *   Кнопка «Завершить бой».
*   Интеграция: в `ChatView.vue` добавить кнопку «Бой» (иконка мечей), которая открывает `CombatTracker`.

### 1.2 Composable
*   `useCombatTracker.js`: загрузка состояния, методы next/prev turn, updateParticipant.

## 2. Риски
*   Drag-and-Drop в Vue без сторонних библиотек может быть сложным. Рекомендуется использовать легкую библиотеку (например, `vuedraggable`), но если мы хотим избежать зависимостей, можно сделать кнопки "выше/ниже" или просто инпуты.
