# Spec: Боевая Секвенция Сцены (Этап 2: UI Линейки)

**Status:** Draft

## 1. Контекст и Цель
После создания ядра боевой секвенции (Этап 1) нам нужен интуитивный интерфейс для управления боем. 
Цель — создать плавающую панель (HoMM-style) с аватарками участников, выстроенными по инициативе, чтобы рассказчик и игроки видели, чей сейчас ход.

## 2. User Stories
*   **US-1:** Как рассказчик, я хочу видеть линейку инициативы с портретами, чтобы понимать очередность.
*   **US-2:** Как рассказчик, я хочу перетаскивать портреты (drag-and-drop), чтобы менять инициативу или перекидывать ход.
*   **US-3:** Как игрок, я хочу видеть, когда наступает мой ход (подсветка и звук), чтобы не пропустить его.
*   **US-4:** Как рассказчик, я хочу добавлять/убирать участников и скрывать их (засада) прямо из этой панели.

## 3. Acceptance Criteria (EARS)
*   **AC-1 (Отображение):** THE system SHALL отображать панель `CombatTracker.vue` при активной боевой секвенции.
*   **AC-2 (Сортировка):** Аватарки сортируются по `initiative` (убывание). Текущий ход выделяется золотой рамкой.
*   **AC-3 (Управление):** У рассказчика есть кнопка «Следующий ход», которая двигает очередь. 
*   **AC-4 (Выбывшие):** Если `is_active = false`, аватар затемняется, перечеркивается красной линией и уезжает в конец списка.
*   **AC-5 (Drag-and-Drop):** Рассказчик может перетащить аватарку, чтобы изменить порядок (PATCH-запрос на обновление `initiative`).

## 4. Out of Scope
*   Синхронизация через WebSockets (Этап 3).
*   Автоматическая фильтрация логов (Этап 3).
