# Plan: Визуальная переделка Чарлиста и Окна Кубиков

## 1. Frontend (Vue 3)

### 1.1 Окно Кубиков (DiceRoller.vue)
*   **Горизонтальный блок:** Обернуть селекты Макроса, Персонажа и Режима в контейнер `div.dice-top-row` (CSS: `display: grid; grid-template-columns: 1fr 1fr 1fr;`).
*   Добавить вертикальные разделители (например, `border-right: 1px solid var(--border)` для первых двух колонок).
*   **Логика скрытия:** 
    *   Если выбран макрос: скрыть блок «Режим броска» (целиком колонку из AC-1) и поле «Пул кубиков» (если оно есть в настройках).
    *   Если выбран «Без макроса»: показать «Режим», «Пул», «Сложность».
*   Поля «Комментарий», «Скрытый бросок» и кнопка «Бросить» остаются внизу без изменений.

### 1.2 Чарлист (CharacterSheetGrid.vue)
*   **Удаление табов:** Убрать массив `tabs` и логику `activeTab`.
*   **Вертикальный лейаут:** Отрендерить все секции друг под другом.
*   **Шапка (Header):** В режиме редактирования сделать инпуты активными. Сохранение отправлять через `PATCH /api/characters/{character}`.

## 2. Риски
*   Скрытие колонки «Режим броска» при выбранном макросе ломает сетку из трёх равных колонок, если колонка остаётся в раскладке пустой.
*   **Вынесено из критериев приёмки:** `DiceRoller.vue`, контейнер `dice-top-row` (`grid-template-columns: 1fr 1fr 1fr`). `CharacterSheetGrid.vue` без `tabs` / `activeTab`, секции друг под другом, класс `.sheet-block`. Шапка — поля внутри грида, `PATCH /api/characters/{character}`. Окно кубов: `floating-window--dice`, 390×440.
