# Spec: Визуальная переделка Чарлиста и Окна Кубиков

**Status:** Completed
**Date:** 2026-11-06

## 1. Контекст и Цель
Текущий интерфейс функционален, но страдает от плохого использования пространства (окно кубов) и не соответствует привычному виду листа персонажа (горизонтальные табы вместо вертикального скролла). Шапка нового чарлиста не редактируется.
Цель — оптимизировать окно кубиков (сделать акцент на макросах) и перевести чарлист в единый вертикальный вид с редактируемой шапкой.

## 2. Acceptance Criteria (EARS)
*   **AC-1 (Кубы - Горизонтальный блок):** THE system SHALL объединить «Выбор макроса», «Выбор персонажа» и «Режим броска» в один горизонтальный блок, разделенный вертикальными линиями на 3 колонки:
    *   Левая: Заголовок «Выбор макроса» (сверху), селект макросов (снизу).
    *   Центр: Заголовок «Выбор персонажа» (сверху), селект персонажей (снизу).
    *   Правая: Заголовок «Режим броска» (сверху), селект режима (снизу).
*   **AC-2 (Кубы - Логика макроса):** WHEN пользователь выбирает макрос, THE system SHALL скрывать «Режим броска» и «Пул кубиков». Остальные поля (Комментарий, Скрытый бросок, Кнопка «Бросить» и прочие) остаются на месте.
*   **AC-3 (Кубы - Без макроса):** WHEN выбран «Без макроса», THE system SHALL показывать все поля, включая Режим броска, Пул, Сложность и Тип куба.
*   **AC-4 (Чарлист - Вертикальный вид):** THE system SHALL убрать горизонтальные вкладки (Табы) и сделать единый вертикальный скролл-лейаут из блоков: Шапка -> Атрибуты -> Способности -> Преимущества -> Статус.
*   **AC-5 (Чарлист - Шапка):** THE system SHALL перенести редактирование Шапки (Имя, Клан, Поколение, Натура, Маска) внутрь самого листа (в режиме редактирования).

## 3. Out of Scope
*   Удаление старых форм внизу страницы — SDD №3.

## Post-Implementation Notes
*   Сборка фронта в Docker (`docker compose run --rm frontend npm run build`) проходит без ошибок.
*   Окно кубиков: верхняя строка из трёх колонок (макрос, персонаж, режим); при выбранном макросе скрываются колонка «Режим броска» и поле «Пул»; окно «Кубы» увеличено по умолчанию (390×440px) через модификатор `floating-window--dice`.
*   Чарлист: единый вертикальный скролл с блоками `.sheet-block`; шапка редактируется внутри грида, сохранение через `PATCH /characters/{id}`; нижняя ручная проверка в браузере на вашей стороне желательна для визуальной приёмки.
