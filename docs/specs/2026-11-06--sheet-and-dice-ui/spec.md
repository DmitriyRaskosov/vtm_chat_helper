# Spec: Визуальная переделка Чарлиста и Окна Кубиков

**Status:** Completed
**Date:** 2026-11-06

## 1. Контекст и Цель
Окно кубов плохо использует место, а лист персонажа листается горизонтальными вкладками и не даёт править шапку. Нужно собрать выбор броска в одну строку и показать лист одним вертикальным списком с редактируемой шапкой.

## 2. User Stories
*   **US-1:** Как игрок, я хочу видеть макрос, персонажа и режим броска в одной строке, чтобы окно кубов не расползалось.
*   **US-2:** Как игрок, я хочу, чтобы при выбранном макросе лишние поля скрывались, а без макроса оставались на месте.
*   **US-3:** Как игрок, я хочу лист одним вертикальным списком, чтобы не переключать вкладки в поисках блока.
*   **US-4:** Как игрок, я хочу править имя, клан, поколение, натуру и маску прямо в листе, пока включено редактирование.

## 3. Acceptance Criteria (EARS)
*   **AC-1:** WHEN открыто окно броска, THE system SHALL показать один горизонтальный блок из трёх колонок, разделённых вертикальными линиями. Слева — заголовок «Выбор макроса» и список макросов. В центре — заголовок «Выбор персонажа» и список персонажей. Справа — заголовок «Режим броска» и список режимов.
*   **AC-2:** WHEN пользователь выбирает макрос, THE system SHALL скрыть «Режим броска» и «Пул кубиков». Комментарий, скрытый бросок, кнопка «Бросить» и остальные поля остаются на месте.
*   **AC-3:** WHEN выбран «Без макроса», THE system SHALL показать все поля, включая режим броска, пул, сложность и тип куба.
*   **AC-4:** WHEN открыт лист персонажа, THE system SHALL убрать горизонтальные вкладки и показать один вертикальный список: Шапка, Атрибуты, Способности, Преимущества, Статус.
*   **AC-5:** WHEN включено редактирование листа, THE system SHALL дать менять шапку (имя, клан, поколение, натура, маска) внутри самого листа.

## 4. Out of Scope
*   Удаление старых форм внизу страницы листа.

## 5. Post-Implementation Notes
*   Сборка фронта в Docker (`docker compose run --rm frontend npm run build`) проходит без ошибок.
*   Окно кубиков: верхняя строка из трёх колонок (макрос, персонаж, режим); при выбранном макросе скрываются колонка «Режим броска» и поле «Пул»; окно «Кубы» увеличено по умолчанию (390×440px) через модификатор `floating-window--dice`.
*   Чарлист: единый вертикальный скролл с блоками `.sheet-block`; шапка редактируется внутри грида, сохранение через `PATCH /characters/{id}`; нижняя ручная проверка в браузере на вашей стороне желательна для визуальной приёмки.
