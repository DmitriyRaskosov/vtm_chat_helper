# Spec: Боевая Секвенция Сцены (Этап 3: Синхронизация и Логи)

**Status:** Draft

## 1. Контекст и Цель
Завершающий этап боевой системы. Нужно связать трекер инициативы с логом бросков и WebSockets, чтобы:
1. Броски во время боя не смешивались с обычными бросками сцены.
2. При переходе хода `active_character_id` обновлялся автоматически.
3. Игроки получали уведомления в реальном времени.

## 2. User Stories
*   **US-1:** Как игрок, я хочу получать пуш/звук, когда наступает мой ход.
*   **US-2:** Как рассказчик, я хочу, чтобы в логе боя отображались только броски текущего боя, а не всё подряд.
*   **US-3:** Как система, я хочу автоматически управлять `active_character_id` при переключении хода.

## 3. Acceptance Criteria (EARS)
*   **AC-1 (Связь с логом):** WHEN происходит бросок кубов, THE system SHALL проверять, есть ли активная боевая секвенция. Если есть — сохранять бросок с `combat_encounter_id`.
*   **AC-2 (Фильтрация):** THE system SHALL отображать в панели «Лог боя» только броски, принадлежащие активному бою.
*   **AC-3 (Авто-ход):** WHEN рассказчик нажимает «Следующий ход», THE system SHALL автоматически обновлять `active_character_id` в сцене на ID текущего участника.
*   **AC-4 (WebSockets):** THE system SHALL транслировать событие `CombatTurnChanged` через Reverb, чтобы у всех обновлялась линейка и включался звук при их ходе.
*   **AC-5 (Завершение):** WHEN бой заканчивается, THE system SHALL очищать `active_character_id` и возвращать обычный режим.
