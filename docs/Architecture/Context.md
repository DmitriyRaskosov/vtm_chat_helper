# Контекст Copilot

Контекст развивается отдельными этапами. Сейчас реализован фундамент токенного бюджета; Context Builder и summaries появятся на следующих этапах [[Project/Roadmap]].

## Слои памяти

1. `messages` — полная сырая история и источник истины.
2. Context summaries — будущая производная сжатая память с provenance по сцене и диапазону сообщений.
3. Рабочий prompt — будущий бюджетированный набор recent messages, summaries и RAG, а не полная история.

## Область контекста

Базовая область — [[Features/Scenes|сцена]]. Каждое сообщение имеет обязательный `scene_id`; история Copilot уже ограничена активной сценой.

## Оценка токенов

`App\Context\TokenEstimator` использует локальную консервативную оценку:

```text
max(1, ceil(число Unicode-символов / CONTEXT_CHARACTERS_PER_TOKEN))
```

По умолчанию один токен оценивается как 3 Unicode-символа. Результат и версия `unicode-chars-v1-cpt3` кешируются в `messages.token_estimate` и `messages.token_estimator_version`; суффикс фиксирует использованный коэффициент.

Это оценка, а не tokenizer конкретной модели. Версия нужна для воспроизводимости и будущего backfill при смене алгоритма.

## Окно L0

`MessageWindowSelector` выбирает старейший непрерывный хронологический префикс:

- не более 6000 оценочных токенов;
- не более 50 сообщений;
- сообщение никогда не режется;
- сообщение, которое не помещается, начинает следующее окно;
- одиночное сообщение длиннее 6000 токенов образует отдельное `oversized`-окно.

На текущем этапе selector готов и покрыт unit-тестами, но автоматическая суммаризация ещё не запускается.
