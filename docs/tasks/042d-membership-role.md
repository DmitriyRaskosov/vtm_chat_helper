# 042d — Роль из членства выбранной хроники

- **Stage:** 3
- **Status:** done
- **Depends on:** 041, 042a, 042b
- **Risk:** med
- **Part:** 4
- **Разрешённые зависимости:** нет

## Goal

Интерфейс считает пользователя рассказчиком только в выбранной хронике, по его членству, и игрок другой хроники не открывает дневник этой.

## Context

- План §«Этап 3», задача 042, четвёртая часть. ADR-007 п. 6: роль из членства.
- 041 задал глобальный computed: `isStoryteller` истинно, если рассказчик хотя бы в одной хронике. Для нескольких хроник это дыра: рассказчик хроники A видит кнопки рассказчика, находясь в хронике B. Здесь формула сужается.
- Правило фронта: не дублировать признак. Импорты `isStoryteller` из `auth.js` остаются. Цикл не создавать: `useCurrentChronicle.js` импортирует `auth.js`, поэтому computed не переносить в composable. Id выбранной хроники уже лежит в composable (042a) — продублировать его чтение через `localStorage` ключ `game-chat-chronicle` и `user.memberships` внутри `auth.js`, либо вынести сам ref id в `auth.js` и читать его из composable. Выбрать один вариант и описать в отчёте.
- `meta.storyteller` в `router.js` смотрит этот computed. Игрок текущей хроники на дневнике → редирект на чат этой хроники, не на голый `/chat`.
- `AppNav` показывает «· рассказчик» от того же computed.
- Переключатель роли в UI не делать (открытый вопрос ADR-007). Роль приходит с сервера, локально не переключается.
- Рассказчик одной хроники может быть игроком другой — данные это позволяют. Проверка как раз этого случая.

## Scope

- `frontend/src/auth.js` — формула `isStoryteller`
- `frontend/src/composables/useCurrentChronicle.js` — отдать выбранный id без цикла импортов
- `frontend/src/router.js` — редирект с `meta.storyteller` на чат текущей хроники
- `frontend/src/components/layout/AppNav.vue` — подпись роли выбранной хроники (текст «рассказчик» / «игрок»)

**Out of scope:**
- бэкенд Policies (038) и матрица (044);
- новый переключатель роли;
- экраны 042b и 042c, кроме редиректа дневника.

## Steps

1. Зафиксировать в отчёте, где живёт ref id, чтобы `auth.js` и `useCurrentChronicle.js` не импортировали друг друга по кругу.
2. `isStoryteller` = у `user.memberships` есть запись с `chronicle_id` выбранной хроники, `role === 'storyteller'` и без `left_at`. Нет выбранной хроники → false.
3. Редирект дневника для игрока — на `/c/:chronicleId/chat` того же id. Нет id — на `/chronicles`.
4. В шапке рядом с именем: «рассказчик» или «игрок» по членству выбранной хроники. Нет хроники — без подписи роли.
5. Ручная проверка двумя пользователями (или одним пользователем в двух хрониках, если 036/037 это уже позволяют): в хронике, где он рассказчик, видны управление сценой и дневник; в хронике, где он игрок, дневник редиректит на чат, кнопки рассказчика скрыты. Обновление страницы не возвращает глобальный признак.
