# Мир (UI)

Рассказчик ведёт справочник хроники, политику фракций и статьи лора. Игрок этот экран не видит. API: [[API/World]], [[API/Lore]]. Канон сущностей: [[Architecture/World]]. Лор: [[Architecture/Lore]].

## Навигация

У рассказчика шапка `Чат · Персонажи · Мир`. Маршрут `/world` (`WorldView.vue`), `meta.storyteller`. Игрок с URL `/world` уходит в чат.

## Справочник

Одна страница, без персонажей (они на [[Features/Characters]]).

Создание и редактирование в одной верхней форме: имя, тип (при редактировании read-only), подтип, краткое описание. Клик по имени в списке открывает запись; «Сохранить» / «Новая». Списки по типам. «Скрыть» архивирует сущность; блок «Скрытые» с «Вернуть». Физического DELETE нет.

Подтипы фракции: секта, клан, котерия, гильдия, другое. Места, предметы и идеи — enum typed-таблиц.

## Политика фракций

Не матрица НПС. Камарилья враждебна Саббату целиком: ребро `hostile_to` или `allied_with` между двумя фракциями. Симметрия на query layer: одна строка. Вражда и союз для одной пары сменяют друг друга. «Снять» завершает ребро.

## Место в мире

На листе персонажа, под биографией. Редактор только у рассказчика: секта (`faction_type=sect`, affiliation `member` + `member_of`), клан (`characters.clan_entity_id`, только `faction_type=clan`), гавань (location, affiliation `resident` + `located_at`). Игрок видит имена read-only.

Селектор «Создать…» шлёт `POST /api/world/entities` и подставляет новую сущность. Котерия и прочие членства этим блоком не трогаются.

## Лор

Вторая вкладка `/world`. Список статей, редактор, скрытые.

- Название, текст, уровень `0`–`5`, чекбокс «ситуационная»; вид — в «Ещё» (дефолт custom)
- Видимость в UI скрыта (API всегда `public`; на Copilot не влияет)
- «О ком статья» и «Исключения» — свёртки, необязательны; фильтр по типу и поиску по имени (скрытые сущности остаются в выбранных id)
- Исключения — grant/deny (`character_lore_knowledge`); для ситуационных — только grant

«Сохранить статью» = `publish` + индекс `lore_chunks`. «Скрыть» архивирует, «Вернуть» восстанавливает. NPC видит статью, если её уровень в наборе допуска на [[Features/Characters|листе]]; ситуационная — только с grant. Биография листа уровнем статьи не режется.

API: [[API/Lore]]. Память NPC в SPA по-прежнему нет.
