# Мир (UI)

Рассказчик ведёт справочник хроники, политику фракций и статьи лора. Игрок этот экран не видит. API: [[API/World]], [[API/Lore]]. Канон сущностей: [[Architecture/World]]. Лор: [[Architecture/Lore]].

## Навигация

У рассказчика шапка `Чат · Персонажи · Мир`. Маршрут `/world` (`WorldView.vue`), `meta.storyteller`. Игрок с URL `/world` уходит в чат.

## Справочник

Одна страница, без персонажей (они на [[Features/Characters]]).

Создание и редактирование в одной верхней форме: имя, тип (при редактировании read-only), подтип, для группы — «входит в группу» (`parent_faction_id`), краткое описание, дополнительные имена (aka). Типы справочника: **группа** (`entity_type=faction`), место, предмет, идея. Клик по имени в списке открывает запись; «Сохранить» / «Новая». Списки по типам. «Скрыть» архивирует сущность; блок «Скрытые» с «Вернуть». Физического DELETE нет.

Подтипы группы: секта, клан, котерия, круг, другое (дефолт новой записи — другое, не секта). Гильдии нет. Места, предметы и идеи — прежние enum typed-таблиц. Алиас — другое имя **того же** узла, не «входит в». Канон — поле «Имя»; список «Ещё имена» пишет только `aka`. Вложенность круга/котерии в секту — select родителя, не алиас.

## Политика фракций

Не матрица НПС. Камарилья враждебна Саббату целиком: ребро `hostile_to` или `allied_with` между двумя фракциями. Симметрия на query layer: одна строка. Вражда и союз для одной пары сменяют друг друга. «Снять» завершает ребро.

## Место в мире

На листе персонажа, под биографией. Редактор только у рассказчика: секта (любая активная `faction`, affiliation `member` + `member_of`), клан (`characters.clan_entity_id` → `entity_type=clan`), гавань (location, affiliation `resident` + `located_at`). Игрок видит имена read-only.

Справочник фракций: подтипы `sect`, `clan`, `coterie`, `circle`, `other`. UI корень `faction` — «Группа». `circle` — круги влияния, советы (Примоген, внутренний круг Камарильи); вложенность через `parent_faction_id`.

Селектор «Создать…» шлёт `POST /api/world/entities` и подставляет новую сущность. Котерия и прочие членства этим блоком не трогаются.

## Лор

Вторая вкладка `/world`. Список статей, редактор, скрытые.

- Название, текст, уровень `0`–`5`, чекбокс «ситуационная»; вид — в «Ещё» (дефолт custom)
- Видимость в UI скрыта (API всегда `public`; на Copilot не влияет)
- «О ком статья» и «Исключения» — свёртки, необязательны; фильтр по типу и поиску по имени (скрытые сущности остаются в выбранных id)
- Исключения — grant/deny (`character_lore_knowledge`); для ситуационных — только grant

«Сохранить статью» = `publish` + индекс `lore_chunks`. «Скрыть» архивирует, «Вернуть» восстанавливает. NPC видит статью, если её уровень в наборе допуска на [[Features/Characters|листе]]; ситуационная — только с grant. Биография листа уровнем статьи не режется.

**Экстрактор (этап 2):** у сохранённой статьи кнопка «Разобрать» (если `EXTRACTOR_DRIVER=ollama`). Список pending-кандидатов под формой: у mention — имя, тип (группа / место / предмет / идея), подтип как в справочнике, «ещё имена» (aka), «это имя уже существующего…». Отдельно «Сохранить правку» (`PATCH`), затем принять / отбросить. Accept с привязкой к существующему узлу пишет aka (`merged`), без второй сущности; extra aliases тоже на этот узел. Новый узел — `create` с подтипом и aka. Персонажей и события мира с лора не создаём. См. [[API/Extract]], [[Project/Extractor]].

Третья вкладка **Разбор** (`/world?tab=inbox`): очередь окон сцены (`needs_review` и `failed`). Failed — переразбор; авто-job то же окно не ставит, пока ошибка не superseded.

API: [[API/Lore]]. Память NPC в SPA по-прежнему нет.
