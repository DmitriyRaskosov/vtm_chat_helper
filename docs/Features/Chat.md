# Chat (фича)

Сценовый чат для всех пользователей — таблица `messages`, API [[API/Messages]].

## Поведение

- Все авторизованные пользователи видят сообщения выбранной сцены активной игровой сессии
- Закрытые сцены доступны для чтения; писать можно только в активную
- Обычная отправка: `body` без `npc_name`/`character_id`, `author` = имя пользователя, `mine` = true для своих
- Реплика персонажа: `character_id` (игрок — свой PC и гули этого PC; НПС и чужие гули — только рассказчик). `author` следует за переименованием канонического имени
- Новые NPC-реплики требуют `character_id`; старые сообщения без `author_character_id` читаются по snapshot `npc_name`
- Сообщения упорядочены по `id`; poll использует одновременно `scene_id` и `after_id`

## UI

`ChatView.vue` — выбор [[Features/Scenes|сцены]], её лента и composer для игроков и рассказчика. Шапка ведёт на [[Features/Characters|листы персонажей]].

Рассказчик в шапке сцены видит блок «На сцене»: текущие участники, селект персонажа и «Добавить» (`POST /api/scenes/{scene}/participants`). Роль берётся из типа: NPC → `npc`, PC → `player`, гуль → `extra`. Закрытая сцена — только список. Copilot ниже выбирает среди текущих NPC этой сцены.

Рассказчик дополнительно имеет панель copilot ([[Features/Copilot]]), кнопку «Разобрать» (sync хвост окна) и бейдж «N окон ждут» → inbox на [[Features/World]] (`/world?tab=inbox`). Авторазбор — фоновые окна по job, не блокирует чат. Кандидаты в бою не показываются.

## RAG

Каждое сообщение индексируется в scoped-корпус `message_embeddings` для семантического поиска ([[API/RAG]]).
