# Chat (фича)

Общий чат для всех пользователей — таблица `messages`, API [[API/Messages]].

## Поведение

- Все авторизованные пользователи видят все сообщения
- Обычная отправка: `body` без `npc_name`, `author` = имя пользователя, `mine` = true для своих
- Сообщения упорядочены по `id`, опциональный poll через `after_id`

## UI

`ChatView.vue` — лента сообщений + composer для игроков и рассказчика (свои реплики).

Рассказчик дополнительно имеет панель copilot ([[Features/Copilot]]).

## RAG

Каждое сообщение индексируется в `rag_chunks` для семантического поиска ([[API/RAG]]).
