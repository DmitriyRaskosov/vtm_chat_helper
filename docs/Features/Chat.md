# Chat (фича)

Сценовый чат для всех пользователей — таблица `messages`, API [[API/Messages]].

## Поведение

- Все авторизованные пользователи видят сообщения выбранной сцены активной игровой сессии
- Закрытые сцены доступны для чтения; писать можно только в активную
- Обычная отправка: `body` без `npc_name`, `author` = имя пользователя, `mine` = true для своих
- Сообщения упорядочены по `id`; poll использует одновременно `scene_id` и `after_id`

## UI

`ChatView.vue` — выбор [[Features/Scenes|сцены]], её лента и composer для игроков и рассказчика.

Рассказчик дополнительно имеет панель copilot ([[Features/Copilot]]).

## RAG

Каждое сообщение индексируется в `rag_chunks` для семантического поиска ([[API/RAG]]).
