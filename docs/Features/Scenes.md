# Игровые сессии и сцены

Сцена — граница ленты сообщений и будущего контекста Copilot. В одной игровой сессии может быть много сцен разной длины, но активна только одна.

## Поведение

- Все сообщения обязательно принадлежат сцене.
- Активная сцена принимает сообщения игроков, рассказчика и НПС.
- `draft`-сцену рассказчик может снова активировать.
- Закрытая сцена доступна для чтения, но не может быть открыта повторно.
- Создание новой активной сцены переводит предыдущую в `draft`; явное закрытие завершает сцену.
- Существующая до миграции история переносится в «Начальную сцену» служебной активной сессии.

## UI

`ChatView.vue` загружает активную игровую сессию и показывает выбор её сцен. При переключении загружается отдельная лента.

Рассказчик может:

- создать игровую сессию из пустого состояния; начальная активная сцена создаётся автоматически;
- создать и сразу активировать сцену;
- активировать ожидающую сцену;
- закрыть активную сцену.

Игрок видит selector и закрытые сцены, но не элементы управления. Если активной сессии нет, он видит состояние ожидания рассказчика. Composer и Copilot доступны только для активной сцены.
