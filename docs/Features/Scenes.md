# Игровые сессии и сцены

Сцена — граница ленты сообщений и будущего контекста Copilot. Хроника (`chronicles`) — корневой scope мира и игровых встреч. В одной хронике одновременно активна не более одной игровой сессии; в сессии может быть много сцен разной длины, но активна только одна. Несколько хроник не разделяют активные встречи, сцены и сообщения.

## Поведение

- Все сообщения обязательно принадлежат сцене.
- Активная сцена принимает сообщения игроков, рассказчика и НПС.
- `draft`-сцену рассказчик может снова активировать.
- Закрытая сцена доступна для чтения, но не может быть открыта повторно.
- Создание новой активной сцены переводит предыдущую в `draft`; явное закрытие завершает сцену.
- Архивация игровой сессии закрывает все оставшиеся active/draft-сцены.
- Существующая до миграции история переносится в «Начальную сцену» служебной активной сессии служебной хроники.
- Создание новой активной сессии архивирует только встречу той же хроники.

## UI

`ChatView.vue` загружает активную игровую сессию служебной хроники и показывает выбор её сцен. При переключении загружается отдельная лента. UI выбора хроники нет.

Рассказчик может:

- создать игровую сессию из пустого состояния; начальная активная сцена создаётся автоматически;
- создать и сразу активировать сцену;
- активировать ожидающую сцену;
- закрыть активную сцену;
- в блоке «На сцене» добавить персонажа на выбранную сцену (селект из листов хроники) и убрать текущего.

Игрок видит selector и закрытые сцены, но не элементы управления. Если активной сессии нет, он видит состояние ожидания рассказчика. Composer и Copilot доступны только для активной сцены.

## Контекст

Канон активной сцены — `scene_contexts` и `scene_participants` (PostgreSQL, не Redis). Context Assembler читает atmosphere, situation, notes, location и текущих присутствующих в блок `## Scene`. Закрытие сцены freeze revision и запрещает правки; историю не сжимает. HTTP CRUD контекста — [[API/Scenes]]. UI правки atmosphere/situation нет; состав сцены редактируется в `ChatView` (блок «На сцене»).

`scene_id` является областью сырых сообщений Copilot. Правила бюджета описаны в [[Architecture/Context]].

См. [[API/Scenes]], [[Features/Chat]].
