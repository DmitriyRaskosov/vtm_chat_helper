Структура проекта game-chat (Laravel 13 + Vue 3)
=================================================

Два приложения: JSON API в Docker (Sail) и Vue SPA в frontend/.
Браузер: http://localhost:5173 (Vite на хосте). API: http://localhost:8080/api.


КОРЕНЬ
------
composer.json / compose.yaml   — PHP 8.4, PostgreSQL+pgvector, Redis, Mailpit, Ollama
.env / .env.example            — порты, RAG, Ollama
sail.cmd                       — Sail под Windows
artisan                        — CLI (через docker compose exec laravel.test)
README.md                      — как поднять стек
ROADMAP.md                     — этапы разработки
PLAN-COPILOT.md                — план copilot (этапы 5–6)
STRUCTURA.txt                  — этот файл


frontend/ — Vue 3 SPA
---------------------
src/views/ChatView.vue    — чат + панель рассказчика (copilot)
src/auth.js               — axios + Sanctum token
vite.config.js            — прокси /api → localhost:8080
Запуск: cd frontend && npm run dev (порт 5173, не в Docker)


app/ — backend
--------------
Http/Controllers/
  ChatController.php      — GET/POST /api/messages
  CopilotController.php   — POST /api/copilot/drafts (storyteller)
  RagSearchController.php — GET /api/rag/search (storyteller)

Http/Middleware/EnsureStoryteller.php

Models/
  User.php                — login, role (storyteller | player)
  Message.php             — body, npc_name (реплика от НПС)
  RagChunk.php            — векторный индекс для RAG

Rag/
  RagIndexer.php          — индексация сообщений и лора
  RagSearcher.php         — поиск по pgvector
  OllamaEmbeddingProvider.php

Llm/
  OllamaChatProvider.php  — qwen3:8b
  NpcCopilotService.php   — сборка промпта + 3 черновика

Jobs/IndexRagMessageJob.php

Enums/RagSourceType.php   — message, lore, npc, relationship (последние — задел)


database/migrations/
  messages                — user_id, body, npc_name
  rag_chunks              — embedding vector(768), HNSW index


routes/api.php            — единственные HTTP-маршруты (без web.php / Blade)


config/
  rag.php, ollama.php, copilot.php


tests/Feature/
  AuthenticationTest, ChatTest, RagSearchTest, CopilotTest


Как склеивается copilot
-----------------------
Рассказчик → POST /api/copilot/drafts
  → последние сообщения чата + RAG (nomic-embed-text)
  → Ollama qwen3:8b → 3 черновика JSON
Рассказчик правит → POST /api/messages { body, npc_name }
  → чат для всех, author = имя НПС, RAG-индекс сообщения

Ollama только внутри Docker: http://ollama:11434 (порт 11434 не на хосте).
